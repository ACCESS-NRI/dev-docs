## Design review

All software architecture decisions must go through an internal design review process.

## Process

  1. Write up a document in the dev-docs wiki describing:
  * Project goals (what problem are we solving?)
  * Languages and frameworks chosen, including brief justification for each
  * Architecture outline or diagram

  2. [Open an issue in the dev-docs wiki](https://github.com/ACCESS-NRI/dev-docs/issues/new) referencing the document.

  3. Assign issue to NRI team. (Requires creating team in ACCESS-NRI organisation)
